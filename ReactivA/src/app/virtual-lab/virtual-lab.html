Normas de Seguridad y Buenas Prácticas

En un laboratorio de química real y en este simulador interactivo, rigen las siguientes normas curriculares de bioseguridad:

  • Uso de EPP: Bata de algodón abotonada, gafas de protección ocular y guantes de nitrilo.
  • Manejo del Mechero Bunsen: Encender con válvula de aire cerrada para obtener llama amarilla luminosa de seguridad, luego abrir el collarín para llama azul oxidante.
  • Dilución de Ácidos: Regla de oro: "Siempre añade el ácido sobre el agua, nunca agua sobre el ácido" para evitar proyecciones por calor de hidratación.

Clasificación de Reacciones Químicas

1. Síntesis (A + B → AB): Dos o más sustancias se combinan para formar un único compuesto más complejo.
2. Descomposición (AB → A + B): Un compuesto se fragmenta en sustancias más sencillas por calor o electrólisis.
3. Combustión (CxHy + O₂ → CO₂ + H₂O): Reacción de un hidrocarburo con oxígeno que libera dióxido de carbono, agua y energía.
4. Sustitución Simple (A + BC → AC + B): Un elemento más reactivo desplaza a otro menos activo en un compuesto disuelto.
5. Doble Desplazamiento (AB + CD → AD + CB): Intercambio de iones entre dos sales o un ácido y una base (neutralización).
